# RELIO web (shadcn/ui)

React + Vite + TypeScript + Tailwind app used to build and preview shadcn/ui components for the RELIO design system, alongside the main vanilla site at the repo root.

## Develop

```sh
bun install
bun dev
```

## Add shadcn/ui components

```sh
bunx shadcn@latest add <component>
```

Components are added under `src/components/ui`.
