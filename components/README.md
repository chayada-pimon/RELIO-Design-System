# components/

Individual component showcase demos. Each subfolder groups related components; put one `.html` (or `.js` partial) per component plus its own notes if needed.

- `buttons/` — primary, secondary, ghost, icon buttons, states (hover/disabled/loading)
- `forms/` — inputs, selects, checkboxes, radios, textareas, validation states
- `cards/` — content cards, stat cards, product cards
- `navigation/` — sidebar, tabs, breadcrumbs, pagination
- `feedback/` — toasts, alerts, modals/drawers, tooltips
- `data-display/` — tables, badges, avatars, lists

Add new subfolders as new component categories come up — no need to pre-create every one.
